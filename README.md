# RentNest

RentNest is a full-stack rental marketplace built with the MERN stack.

Live Demo:
https://rentnest-eight.vercel.app

Features
- User Authentication
- Property Listings
- Booking System
- Stripe Payment
- Khalti Payment
- Owner Dashboard
- Admin Dashboard
- Chat System
- Google/OpenStreetMap Integration
- Image Upload
- Responsive Design

Tech Stack
- React
- Next.js
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- JWT
- Cloudinary

Installation
git clone ...
npm install
npm run dev
